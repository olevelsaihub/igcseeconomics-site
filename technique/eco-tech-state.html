Pearson Edexcel · International GCSE Economics · 4EC1

State or identify: give one correct point (1 mark)

Pearson's meaning of State: a short answer of one sentence at most, about a piece of information from the specification. Identify works the same way in 4EC1: name one thing. No explanation is needed.

Command words: State, IdentifyUsually 1 markAbout 1 minute

What Pearson asks

Pearson's meaning of State: a short answer of one sentence at most, about a piece of information from the specification. Identify works the same way in 4EC1: name one thing. No explanation is needed.

How the marks are earned

One AO1 mark for any one correct point, such as a role, an advantage, a trade-off or a formula. Many different answers are accepted. Only the first answer is marked, so a wrong first answer followed by a right one may not score.

Method

  1. Check how many points are asked for (usually 'one').

    Why: Only the first point counts.

  2. Write the point in a few words or one short sentence.

    Why: State needs no explanation, so do not waste time.

  3. For a formula, write it with clear terms, e.g. social cost = private cost + external cost.

    Why: The formula itself is the answer.

Answer frame

One (role / advantage / trade-off) is ... .

Common errors

Inferred, not measured: Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

  • Writing a long explanation when one phrase is enough.
  • Giving several answers in the hope one is right; only the first is marked.
  • Being too vague, for example 'it helps trade' instead of a clear role.
  • Writing a formula with the terms reversed or one term missing.
