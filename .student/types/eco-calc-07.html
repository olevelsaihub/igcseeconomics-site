Total cost from fixed and variable costs

Building or decomposing total cost: TC = TFC + AVC x Q, or finding TFC or TVC as TC minus the other component.

★★★☆☆ · 9 of 20 eligible examination papers, 2019–2025. Difficulty: Easy.

Knowledge card

Total cost from fixed and variable costs

Calculation

Total cost = fixed cost + total variable cost. Multiply the cost per unit by output first, then add the fixed cost.

Find the readings you need for the bakery's total cost.

  1. Fixed: $3,500
  2. Variable: × output
  3. Total: $5,500

Fixed: $3,500

Why
Rent stays the same whatever the output.

Variable: × output

Step 1
$0.40 × 5,000 = $2,000

Total: $5,500

Step 2
$3,500 + $2,000 = $5,500

Exam tipNever add $0.40 straight to $3,500. Multiply by output first.

2

The calculation

TC = FC + (VC per unit × Q)

Tap a part to see what it means and how to find it.

To find FC:FC = TC − TVC

To find TVC:TVC = TC − FC

  • Multiply by Q before adding.
  • Give the answer in $.

Try itFixed cost $1,200; $5 per unit; 400 units. Find total cost.

  1. TVC = $5 × 400 = $2,000
  2. TC = $1,200 + $2,000
  3. TC = $3,200

A firm has fixed costs of $800 and a variable cost of $2 per unit. Calculate total cost at 300 units. (2 marks)

Tap an answer to see if it earns the mark.

5

The method

  1. Variable part

    Cost per unit × output = total variable cost.

  2. Add or subtract

    TC = FC + TVC. If TC is given, subtract the part you know.

  3. One line

    Write it all: FC + (cost per unit × Q) = answer.

  4. Units

    Finish with $.

Do not lose marks here

  • ✗
    No multiplying

    Adding cost per unit to FC skips the output.

  • ✗
    Dividing

    Dividing by output gives an average, not a total.

  • ✗
    Wrong rate

    A per-day cost is not a per-km cost.

Worked explanation

  1. Total variable cost = $250 x 750 = $187,500.
  2. Total cost = fixed cost + variable cost = $50,000 + $187,500.
  3. Total cost = $237,500 per month.
Model answer · written by olevels.com, not an official Pearson mark scheme

Total costs = $50,000 + ($250 x 750) = $50,000 + $187,500 = $237,500 per month.

How the marks are earned

Two marks. One for the line $50,000 + ($250 x 750), one for $237,500 with the dollar sign. A correct figure with no working still earns both.

Calculation check

  • 250 × 750 = 187500
  • 50000+250 × 750 = 237500
