Knowledge card

Percentage change, including inflation from a price index

Calculation
  • Percentage change = (new value - old value) / old value x 100.
  • Always divide by the old (earlier) value.
  • A fall gives a negative percentage change; keep the minus sign unless the question asks for the 'percentage decrease'.
  • Inflation is the rise in the general price level, measured by the change in the consumer price index (CPI).
  • If the base year index is 100, inflation since the base year = index - 100 (as a %).
  • To scale a basket price by the index: new price = old price x new index / old index.

Before you begin

  • Meaning of inflation and the CPI
  • Negative numbers
  • Rounding to two decimal places
1

The method

  1. Pick the old (earlier) value and the new (later) value; skip middle years not asked for.

    Why: The question's two dates decide which numbers to use.

  2. Find the change: new - old.

    Why: This keeps the sign right for a rise or a fall.

  3. Divide by the old value and multiply by 100, writing the full expression.

    Why: The change is compared with where you started; showing it earns the working mark.

  4. For a base-100 index, the answer is simply index - 100; for a basket price, multiply by new index / old index.

    Why: These are the shortcuts the index versions use.

  5. Round to two decimal places if asked and add the % sign.

    Why: The answer mark needs the % sign and the right precision.

Do not lose marks here

  • ✗
    Dividing by the new value instead of the old value.
  • ✗
    Using a middle year from the table instead of the two years asked.
  • ✗
    Leaving off the % sign, which costs the answer mark.
  • ✗
    Treating index minus 100 as inflation when the base index is not 100.
  • ✗
    Dropping the minus sign when the value has fallen.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

How each command word is answered

Command wordTimes askedWhat to write
Calculate15Write (new - old) / old x 100 with the numbers, then the percentage to two decimal places with %.
multiple-choice4Divide the change by the starting index or price; options using the end value or index - 100 are traps unless the base is 100.

Now see it used on a real past-paper question

What a complete response includes

One mark for change over original value times 100 with the right figures; one mark for the correctly rounded percentage with the % sign. The number without % usually earns one mark only.

Worked explanation

  1. The question asks about 2017 to 2019, so ignore 2018.
  2. Change in profit = $87,100 - $80,750 = $6,350.
  3. Percentage change = 6,350 / 80,750 x 100 = 7.8637...%.
  4. Round to two decimal places: 7.86%.
Model answer · written by olevels.com, not an official Pearson mark scheme

Percentage change = (87,100 - 80,750) / 80,750 x 100 = 6,350 / 80,750 x 100 = 7.86% (to 2 d.p.).

How the marks are earned

Two marks. One for the change divided by the 2017 profit, times 100. One for 7.86% with the % sign and rounded to two decimal places. The right answer alone earns both.
