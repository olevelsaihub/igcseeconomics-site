Finding the average (mean) of data

Calculation

The mean (average) is the sum of all the values divided by how many values there are. Keep the data's unit, such as % or $bn.

3 steps to find

Find the steps to the mean unemployment rate.

  1. Add every value
  2. Count the values
  3. Mean: 27.5 ÷ 5

Add every value

Sum
6.2 + 4.8 + 7.5 + 5.1 + 3.9 = 27.5

Count the values

Why
Five regions, so divide by 5.

Exam tipCount the rows of data, not the headings.

Mean: 27.5 ÷ 5

Answer
27.5 ÷ 5 = 5.5%

3 steps to find

Find the steps to the average yearly FDI.

  1. Line up the decimals
  2. Sum: 59.84
  3. Average: 59.84 ÷ 4

Line up the decimals

Why
Add carefully: 15.80 has two decimal places.

Sum: 59.84

Sum
12.36 + 15.80 + 14.25 + 17.43 = 59.84

Average: 59.84 ÷ 4

Answer
59.84 ÷ 4 = $14.96bn

Exam tipKeep the unit: $bn, not just 14.96.

2

The calculation

Mean = sum of the values ÷ number of values

Tap a part to see what it means and how to find it.

To find Sum:Sum = Mean × n

To find n:n = Sum ÷ Mean

  • Divide by the number of values, not by 2.
  • Round to two decimal places and keep the unit.

Try itInvented inflation rates: 2.4%, 3.1% and 2.9%. Find the mean.

  1. Sum = 2.4 + 3.1 + 2.9 = 8.4
  2. n = 3
  3. 8.4 ÷ 3 = 2.8%

The method

  1. Add them all

    Every value in the table goes in.

  2. Count and divide

    Write the sum ÷ the count.

  3. Round and label

    Two decimal places, with % or $bn.

Do not lose marks here

  • ✗
    Wrong count

    Count the values before dividing.

  • ✗
    Decimal slips

    Line up the decimal points.

  • ✗
    No unit

    Give % or $bn with the answer.

Worked explanation

  1. Sum of FDI = 45.14 + 55.55 + 60.98 + 64.37 = 226.04 ($bn).
  2. There are 4 years, so divide by 4: 226.04 / 4 = 56.51.
  3. Answer: $56.51bn.
Model answer · written by olevels.com, not an official Pearson mark scheme

Average FDI = (45.14 + 55.55 + 60.98 + 64.37) / 4 = 226.04 / 4 = $56.51bn a year.

How the marks are earned

Two marks. One for the sum of the four values over 4. One for $56.51bn with its unit. The correct answer alone earns both.
