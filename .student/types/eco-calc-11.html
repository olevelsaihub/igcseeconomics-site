Knowledge card

Labour productivity: output per worker

Calculation

Labour productivity is output per worker: total output ÷ number of workers. It is measured in units of output, never in money.

The method

  1. Take total output

    For the period given.

  2. Divide by workers

    Output ÷ workers.

  3. Check the unit

    Units of output, not $.

Do not lose marks here

  • ✗
    Upside down

    Workers ÷ output gives a tiny number.

  • ✗
    Multiplying

    Output × workers is huge.

  • ✗
    Money option

    $ is never right.

Worked explanation

  1. Labour productivity = total output / workers = 33,750 / 135 = 250.
  2. Productivity is in units, not dollars, so $250 is wrong.
  3. Answer: C, 250 units.
Model answer · written by olevels.com, not an official Pearson mark scheme

C. Labour productivity = 33,750 units / 135 workers = 250 units per worker each month.

How the marks are earned

One mark for choosing C, 250 units. Option A has the right number but the wrong unit (money), and B and D come from multiplying instead of dividing.
